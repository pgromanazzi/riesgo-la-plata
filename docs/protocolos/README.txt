Carpeta para los protocolos definitivos en PDF, JPG, JPEG, PNG o WebP.

La entrega inicial enlaza los protocolos de https://riesgolaplata.org/Protocolos/.
Para usar archivos propios:
1. Copiarlos aquí manteniendo un nombre único por archivo.
2. Cambiar protocolos_base a "protocolos/" en ../config.json.
3. Completar el campo protocolo en ../data/barrios.geojson con el nombre exacto.
4. Ejecutar node tools/validar-datos.mjs desde la raíz del proyecto.

Ejemplo: "protocolo": "LP-B01.pdf".
No dejar este ejemplo como vínculo si el archivo no existe.
