Cómo usar el visor

  1. Elegí una delegación. Usá el listado, el selector o un clic sobre el mapa.
  2. Encontrá un barrio. Buscá por nombre, código o cuenca. Con una delegación elegida, la búsqueda se limita a ella.
  3. Consultá el protocolo. Seleccioná un barrio y presioná «Ver protocolo». Podés abrir el archivo en otra pestaña.
  4. Compartí la consulta. «Copiar enlace al barrio» conserva la selección. «Ver todo» vuelve al partido completo.
